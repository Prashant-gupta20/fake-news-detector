Frequently Asked Viva Questions & Answers

Prepare for professor and external examiner questions with these technical talking points.

Passive-Aggressive algorithms are online margin-based learning algorithms tailored for high-dimensional, sparse text data. When a sample is classified correctly, the model remains passive (parameters unchanged). When an error occurs, it makes an aggressive step update to satisfy the margin constraint with minimal perturbation. It offers faster convergence and handles streaming news updates better than batch algorithms like SVM.

TF-IDF (Term Frequency - Inverse Document Frequency) balances how frequently a term appears in a document against how common it is across the entire corpus. We enabled sublinear_tf=True which replaces raw frequency tf with 1 + log(tf). This reflects diminishing returns: twenty occurrences of the word "shocking" in one sensational article should not have 20x the weight of a single occurrence.

Standard Passive-Aggressive classifiers only output raw margin distances rather than probabilities. To convert decision distances into well-calibrated posterior probabilities, we wrapped the classifier in Scikit-Learn's CalibratedClassifierCV using sigmoid calibration (Platt scaling) with 3-fold cross validation. This guarantees calibrated probabilities between 0% and 100%.

Pure ML models are black boxes that output a single probability without explaining why. Our system couples the statistical TF-IDF classifier with an interpretable linguistic inspection pipeline (sensationalism scoring, shouting word ratios, citation attribution) and semantic synthesis. This provides both instant classification and actionable transparent explanations.

Overfitting is controlled via 3 mechanisms: 1) Limiting vocabulary to top 5,000 informative n-grams; 2) Regularization parameter C=0.5 in the Passive-Aggressive loss function to penalize aggressive weights; and 3) Stratified train-test splits ensuring balanced class representation across iterations.

1-Click Free Deployment Guide (Render / Railway / Vercel)

Step-by-step instructions to take this application live on the web for free.

🚀 Production Ready
1

Push Code to GitHub

Initialize a git repository in your project directory and push to your GitHub account:

git init
git add .
git commit -m "TruthLens Fake News Detector Initial Commit"
git branch -M main
git remote add origin https://github.com/<your-username>/fake-news-detector.git
git push -u origin main
2

Deploy for Free on Render.com (Recommended)

Render provides 100% free hosting for Python FastAPI web services:

  1. Create a free account on render.com.
  2. Click New + ➜ Web Service.
  3. Select your GitHub repository fake-news-detector.
  4. Set the following parameters:
    • Runtime: Python 3
    • Build Command: pip install -r requirements.txt
    • Start Command: uvicorn backend.main:app --host 0.0.0.0 --port $PORT
  5. Click Deploy Web Service. Within 2 minutes, your live HTTPS URL will be active!
3

Optional: Configure Gemini AI Key for Real-time LLM Explanations

The system runs 100% offline out-of-the-box. If you want live LLM reasoning, simply add an environment variable in Render:

Key: GEMINI_API_KEY
Value: <your_gemini_api_key>
